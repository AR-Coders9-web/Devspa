# Task Nova

Task Nova is a modern Todo application built using HTML, CSS, and JavaScript. It allows users to create, edit, delete, and manage tasks with user-specific localStorage and dark mode support.

## Features
- User Authentication (LocalStorage)
- User-specific Tasks
- Add, Edit & Delete Tasks
- Dark/Light Theme
- Responsive UI

---

## Parsing
Parsing is the process where the browser reads the HTML document and converts it into a DOM structure that JavaScript can access.

## Tokenization
Tokenization is the first step of parsing where the browser breaks the HTML code into tokens such as tags, attributes, and text.

## DOM Tree
The browser converts HTML into a Document Object Model (DOM) tree. JavaScript uses this tree to dynamically create, update, and delete task cards.

## CSSOM Tree
The browser parses CSS and creates the CSS Object Model (CSSOM), which contains all styling rules used in the application.

## Render Tree
The browser combines the DOM Tree and CSSOM Tree to create the Render Tree, which is responsible for displaying the visible UI.

## Event Bubbling
Event Bubbling is when an event starts from the target element and moves upward through its parent elements. Button click events in this project follow the bubbling phase.

## Event Capturing
Event Capturing is the opposite of bubbling. Events travel from the document to the target element before reaching the target.

## Event Delegation
Event Delegation is a technique where a parent element handles events from its child elements. It improves performance by reducing the number of event listeners.
